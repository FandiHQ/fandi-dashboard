# Fandi · Handoff para Claude Code

Pon esta carpeta completa en tu repositorio como `design-handoff/` y pega el mensaje de `CLAUDE_CODE_PROMPT.md`.

| Archivo | Para qué |
|---|---|
| DESIGN_GUIDELINES.md | Reglas del sistema para móvil y web |
| design-tokens.css / .json | Colores, tipografía, radios, sombras y economía |
| Fandi Fan App.dc.html | Referencia visual: 14 pantallas del fan (ábrelo en el navegador) |
| Fandi Artist Dashboard.dc.html | Referencia visual: 8 pantallas web |
| support.js | Necesario para que los dos .html se vean |
| assets/ | Logo, póster e insignias |
| CLAUDE_CODE_PROMPT.md | Lo que le dices a Claude Code |

**¿Capturas de pantalla?** No hace falta. Claude Code lee el código de los .html, con medidas y colores exactos, y puede abrirlos y capturarlos él mismo. Las capturas solo agregan una fuente que se desactualiza.
